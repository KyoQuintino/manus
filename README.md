# manus

Este repositório contém a implementação inicial da **snapgen.ai API**.

## Componentes

- [`snapgen-api/`](./snapgen-api/) — API REST assíncrona para geração de imagens, texto‑para‑vídeo e imagem‑para‑vídeo.
- [`landing-ofertas-github.zip`](./landing-ofertas-github.zip) — landing page estática existente.

Consulte [`snapgen-api/README.md`](./snapgen-api/README.md) para endpoints, exemplos `curl`, configuração de provedor e instruções de execução.
